# Vrindha Store – Annual Sales Analysis Dashboard

An interactive and professionally designed **Excel Sales Analytics Dashboard** built to analyze store sales performance, customer demographics, order status, and sales distribution across different states and channels.

## Dashboard Preview

![Vrindha Store Dashboard](./Screenshot%20(1548).png)

## Project Overview

The Vrindha Store Sales Analysis Dashboard transforms raw retail sales data into meaningful business insights using Microsoft Excel.

The dashboard provides a visual overview of sales trends, customer purchasing patterns, order distribution, and state-wise sales performance through interactive charts and slicers.

## Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Interactive Slicers
- Data Cleaning and Analysis
- Data Visualization

## Dashboard Features

The dashboard includes six interactive visualizations:

1. **Orders vs Sales:** Monthly comparison of sales amount and order count.
2. **Sales: Men vs Women:** Gender-wise sales distribution.
3. **Order Status:** Analysis of delivered, returned, and refunded orders.
4. **Order Channel:** Sales distribution across shopping channels.
5. **Top 5 States:** State-wise sales performance.
6. **Orders Age vs Gender:** Customer order distribution across age groups and gender.

## Interactive Filters

The dashboard includes slicers for:

- Category
- Channel
- Order ID

These filters help users explore different segments of the sales data.

## Key Business Insights

The dashboard helps identify:

- Monthly sales and order trends.
- Gender-wise customer purchasing patterns.
- Order fulfillment and return distribution.
- Popular sales channels.
- Top-performing states.
- Customer age-group purchasing behaviour.

## How to Use

1. Download the Excel workbook from this repository.
2. Open it using Microsoft Excel Desktop.
3. Navigate to the `PROJECT REPORT` sheet.
4. Use the available slicers to filter the dashboard.
5. Explore the charts to understand sales performance.
