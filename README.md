# Vrindha Store -- Annual Sales Analysis Dashboard

An interactive Microsoft Excel dashboard for exploring Vrindha Store's
annual sales performance, customer segments, order status, sales
channels, and state-wise sales.

## Project Overview

The **Vrindha Store Annual Sales Dashboard** turns retail sales data
into a visual report that helps users explore sales trends and
customer/order patterns. The report is built in Microsoft Excel using
PivotTables, PivotCharts, and slicers.

This repository contains the Excel workbook and this project
documentation. **No screenshot is required for the README**; the
dashboard can be viewed directly by opening the workbook in Excel
Desktop.

## Dashboard Contents

The `PROJECT REPORT` worksheet brings together six visualizations:

  -----------------------------------------------------------------------
  Dashboard visual                    What it shows
  ----------------------------------- -----------------------------------
  Orders vs Sales                     Monthly sales amount and order
                                      count

  Sales: Men vs Women                 Gender-wise sales distribution

  Order Status                        Distribution of delivered,
                                      returned, and refunded orders

  Order -- Channel                    Order distribution by sales channel

  Sales: Top 5 States                 Sales comparison across the top
                                      five states shown in the report

  Orders Age vs Gender                Order distribution across age
                                      groups, split by gender
  -----------------------------------------------------------------------

## Interactive Filters

The dashboard workbook includes these slicers:

-   **Category** -- filter results by product category.
-   **Channel** -- filter results by sales channel.
-   **Order ID** -- filter the report to selected order IDs.

Use the slicers in Excel Desktop to explore the report. The available
filters and chart responses depend on the PivotTable connections in the
workbook.

## How to Open and Use the Dashboard

1.  Open `Vrindha_Store_Professionally_Formatted.xlsx` in **Microsoft
    Excel Desktop**.
2.  If Excel displays a Protected View bar, use **Enable Editing** only
    if you trust the workbook source.
3.  Select the `PROJECT REPORT` worksheet.
4.  Use the Category, Channel, and Order ID slicers to filter the
    report.
5.  Select slicer items to explore different parts of the sales data.
6.  Clear a slicer's filter to return to the unfiltered view.

> Note: GitHub does not render interactive Excel workbooks as dashboards
> in the repository page. Download the `.xlsx` file and open it in
> Microsoft Excel Desktop to use the charts and slicers.
